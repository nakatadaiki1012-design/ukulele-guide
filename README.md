# 🎶 ウクレレ・ハンドガイド

ウクレレのコードの押さえ方を、**3Dのリアルな手の形**で見せる練習アプリです。
`index.html` をブラウザで開くだけで動きます（インストール不要）。

## できること
- **3Dの手で押さえ方を表示**：解剖学の計測値（指の骨の長さ・関節の曲がり方）をもとに、指の関節角度を計算して手の形を作ります。指先は真上から、他の弦に触れないように、無理のない角度で押さえます。
- **見る向きを切り替え**：ななめ／自分目線／正面（向かい合った先生から）／横から。画面を**ドラッグすると回せます**。左右反転もできます。
- **コード表**：3D画面の左下に、いまのコードの縦のコード表を小さく表示します（設定で消せます）。練習・曲デモの演奏中は「いま → 次 → その次」の3つを並べ、次のコードまで1拍を切ると次のコード表がオレンジに光ります。
- **全画面**：3D画面右上の「⛶」で全画面に。全画面では、コードのボタンと再生ボタンが3D画面の下に重なって表示されます（再生ボタンの左の曲名を押すと、練習と曲デモを切り替え）。「✕」かEscキーで元に戻ります。縦長のスマホでも、指板が見切れないように見える範囲を広げます。
- **カメラで見比べる**：3D画面右上の「📷」で内カメラをオンにすると、3Dの横（スマホの縦向きでは下）に自分の映像が並びます。「小窓にする」で3Dの上に重ねる小窓にもでき、ドラッグで動かせて「⤢」で大きさ（小・中・大）を変えられます。「⇋」で左右反転、「3Dを合わせる」で3Dを正面＋左右反転にして、カメラに映る自分と同じ向きにします。全画面でも使えます。映像はこの端末の中で表示するだけで、どこにも送ったり保存したりしません（カメラは https のページで使えます）。ギター・ハンドガイドと同じしくみです。
- **自分で作る進行**：練習の「進行」で「✏️ 自分で作る」を選ぶと入力欄が出ます。コード名をスペースで区切って書くと（例：`C Am F G7`、1つ＝1小節）、その進行で練習できます。`Bb`・`A#`→B♭、`am`→Am のような書き方も読み取り、使えないコードは教えてくれます。書いた進行は次に開いた時も残ります。
- **168コード**：根音12種類（C・C♯・D・E♭・E・F・F♯・G・A♭・A・B♭・B）× 14種類（メジャー／m／7／m7／maj7 と、「その他」の sus4／6／m6／7sus4／add9／sus2／dim／aug／m7-5）。根音のボタンはピアノの鍵盤の形（半音は黒鍵）で1段に収め、めったに使わない種類は「その他」を押した時だけ出ます。よく使うコードは手で書いた押さえ方、それ以外はプログラムが「コードの音だけが鳴る・必要な音がそろう・低い位置・指の開きが小さい」押さえ方を自動でさがし、指の割り当て（セーハも）まで決めます（`src/chordgen.js`）。自分で作る進行では `C#m`・`Bm7b5`・`G7sus` のような書き方も読み取ります。
- **手を半透明に**：手を透かして、押さえる場所の印（指の色の丸）と、弦が指に当たって沈んでいるところ（光る輪）を見せます。
- **右手のストローク**：右手も3Dで表示。人差し指は付け根側の2つの関節を軽く曲げた「かぎづめ」の形（指先側の関節は少しゆるめる）で、指全体が弦に対して垂直に近く、中指〜小指は軽く握り込みます。前腕は止めたまま、手首の関節を支点に手首から先だけを動かします（水滴を振り払うようなスナップ）。手首は小指側へ少し倒して手を床の方へ垂らし、ダウンでは人差し指の爪の外側（中指側）が弦に約40°で当たります。振り始めはゆっくり、弦を通る瞬間がいちばん速く（弦の上にいる時間は8分音符の約14%で、音がバラけず「ジャン」とひとつに）、1弦・2弦側を少し深く通ります。アップは指を丸めて指の腹で当て、弦を抜けたら外へ大きく回らず、体から離れる向き＋上へまっすぐ引き上げます。振り終わりには手首が少しだけ跳ね返ります。ダウンは大きく・アップは小さく、1拍目は少し強く、毎回ほんの少しずつ振り幅がばらつきます。前腕はウクレレの尾側（ボディのおしり側）から、ボディの上の縁に沿ってほぼ水平に伸びてきます（手首はボディの表から約7cm、手は前腕の延長に近い向きで、指先側を小指側へ少し倒して弦に向けます）。「弾き語り練習」では、ダウン4つ／8ビート／カリプソ／バラードのパターンを選ぶと、↓↑の譜面が光り、音と右手の動きがリズムに合わせて動きます。弾かない拍は、手を少し浮かせて空振りします。
- **演奏デモ**：Slow & Easy（平井大。コード進行とストロークの伴奏だけ。メロディは著作権があるので入れていません）、ハッピーバースデー・トゥー・ユー、きらきら星（メロディ付き）、アロハ・オエ（メロディ付き・16小節）、カイマナヒラ（オルゴール編曲のMIDIをそのまま鳴らす）。1小節カウントしてから、コード譜が光り、左手のコードチェンジと右手のストロークが曲に合わせて動きます。Slow & Easy 以外は著作権の切れた曲です。
- **腕は手首の少し先まで**：両腕とも手首から先だけを見せ、その先はだんだん透明にして消しています。
- **スイング**：練習・曲デモで「スイング」を押すと、裏拍を少し遅らせて「タッカ・タッカ」とはずむリズムになります（音・手・光る位置すべて）。
- **アングル・2画面**：3D画面の左上「🎥」ボタンを押すたびに向きが変わります。「2画面」で左右に別の向きを同時に表示でき、どちらもドラッグで回せます。2本指（マウスは右ドラッグ）で平行移動、ピンチ（ホイール）で拡大。
- **設定（3D画面右上の⚙）**：背景（昼の砂浜・夕焼けの砂浜・夜の砂浜・海の家・野原）、ウクレレの柄（マホガニー・ハワイアンコア・スプルース・ブラック・パステル）、右手（いつも表示・演奏中だけ・表示しない）、2画面・半透明・指番号・左右反転・コード表のオン／オフ。選んだ設定は次に開いた時も残ります。速さ（×1〜×¼）は練習・曲デモの再生ボタンの横にあります。
- **右手の表示・スロー再生**：右手は「いつも表示／演奏中だけ／表示しない」を選べます。「速さ」で練習・演奏デモをふつう／3/4／1/2／1/4の速さで再生できます（音も手もいっしょにゆっくりになります）。
- **音と手がぴったり合う**：音を鳴らす時計（Web Audio）と同じ時計で手を動かし、スピーカーから聞こえるまでの遅れも計算に入れています。左手は、次のコードの音が鳴る瞬間にちょうど押さえ終わるように、少し前から動き始めます。
- **なめらかな動き**：右手の動きをならし、重い端末では動いている間だけ自動で解像度を下げます。曲で使うコードの手の形は演奏前に計算しておきます。
- **指がくっつかない**：指どうしがぶつからないように持ち方をシミュレーションし、同じフレットに並ぶ指は指の順番どおり斜めに並べます。
- **音で確認**：ジャラーンと鳴らす／1本ずつ鳴らす（画面タップ・スペースキーでも鳴ります）
- **コードチェンジ練習**：定番の進行を選んで▶。メトロノームに合わせて手が次のコードへ動きます。

## 背景・処理の軽さ
- **軽さ（画質）の3段階**：端末に合わせて自動で「きれい／ふつう／軽い」を選びます（パソコンは「きれい」、スマホは「ふつう」、メモリやCPUが少ないスマホ・画面がとても細かいスマホ・弱いGPUは「軽い」）。⚙ →「軽さ」で手動でも選べます（変えると読み込み直します）。
  - きれい：解像度1.5倍まで・ふち取りあり・影2048・手の表面を2回なめらかに・背景の絵は等倍
  - ふつう：解像度1.25倍・影1024・手の表面を1回なめらかに（三角形の数が約12万→約4万）・背景や木目の絵は半分
  - 軽い：解像度1倍・ふち取りなし・影なし・背景や木目の絵は4分の1
- **すぐ出る手の形**：手の形の計算は1つ0.3〜1秒かかるので、全168コードの手の向き・位置をあらかじめ計算して表（`src/pose-table.js`）に入れておき、押した時はそこから組み立てるだけにしています（1コード約0.015秒）。手の形の決め方（`src/pose.js`）を変えた時は、`npm run build` → `node tools/make-pose-table.mjs` → もう一度 `npm run build` で表を作り直します。
- **演奏中にカクつかない工夫**：手の形の先読み計算（1つ0.1〜0.3秒かかる）は、演奏中や手・カメラが動いている間は止めて、止まっている時だけ進めます。解像度の自動調整は3段階だけにして、変えるのは重い・軽いがしばらく続いた時だけ（解像度を変えること自体が重いため）。右手の振りの形と弦の音も、ひまな時に先に作っておきます。
- **なめらかな操作**：3Dの回転には慣性があり、指を離してもスッとなめらかに止まります。影は手が動いた時だけ描き直し（カメラを回すだけなら前の影のまま）、手の形が変わっていない時は手の計算もしません。カメラを回している間も、重い端末では自動で解像度を下げます。（ギター・ハンドガイドと同じしくみ）
- ウクレレは演奏する時と同じように立てて構え、指板が正面（客席）を向いています。
- 3Dの背景は実物大。ウクレレの約90cm下が地面（近くで見ると砂粒や草が見える）、砂浜では弾く人の後ろ約2.6mに波打ち際、その先に海と水平線。夕焼け・夜は光の色や明るさも変わり、海に太陽・月の光の道ができます。海の家は木のデッキと屋根・手すり、野原は草地と遠くの丘。画像ファイルは使わず、その場で描いています（選んだ時に初めて作ります）。
- 重い端末では、動いている間だけ自動で解像度を下げ、それでも重い時は影を切ります（解像度は最大1.5倍、影の細かさは控えめ）。
- 押さえる場所の印は作り置きして使い回し、毎コマ作り直さないので、長く演奏しても重くなりません。肌の質感も軽い方式にしています。

## 画面の構成
- パソコン：左に3Dの手、右にコード選びと「練習／曲デモ」のタブ。スクロールなしで全体が見えます。
- スマホ：上に3Dの手、下にコード選びとタブ。

## 手とウクレレの形のしくみ
- **手**：関節に骨が入ったリアルな手の3Dモデル（WebXR Input Profiles の generic-hand、MIT License）を使い、
  関節の角度を計算で決めて動かしています。表面は細分割でなめらかにしています。
  - 骨の長さ・指の付け根の位置はモデルの実寸。第一関節は第二関節の約0.75倍だけ曲がる（小指は約0.6倍）という計測値を使用。
  - 指先は真上から、他の弦に触れないように、関節が無理な角度にならないように、の3つを満たす形を選びます。
  - **持ち方のシミュレーション**：手の向き（ひねり・傾き・回転）と位置を少しずつ変えながら、「指先が弦に届く」「関節に無理がない」「手のひらがネックにめり込まない」「手首が曲がりすぎない」「親指がネックの上の肩にかかり、先が上からのぞく」を合計して、いちばん無理のない持ち方を自動で選びます（`src/pose.js`）。
  - 手のひらはネックから離します：指の付け根（人差し指→小指）がネックの表面から離れていてほしい距離を、人差し指側はネックにつけてよく（約12mm）、小指側ほど大きく（約41mm）しているので、手のひらが斜めになって、指をのばして斜めから押さえる形になります（`src/pose.js` の `HAND_CFG.palmGap`。数字を大きくするほどネックから離れます。人差し指の付け根は `indexNear` で、ネックの近くを好みます）。
  - ネックのヘッド側（ナット寄り）を手のひらに乗せるように持ちます：手全体を、指先の真下より12mmヘッド側にずらし、指を少しのばして届かせます（`HAND_CFG.headShift`。大きいほどヘッド寄り）。ずらすほど指の付け根の曲がりが楽になり、人の指の限界を超える曲がりの指は全168コードで11本→4本に減りました。
  - ネックの上の方（ヘッド寄り）を握る形：手を、指先の真下より24mmヘッド側にずらしています（`headShift`。付け根がナットの縁に着く約30mmが限界）。セーハの第二関節は弦の外側（A側）で弦の面に沿わせ、1フレットを押さえる指はナットに触れない位置にして、全168コードを自動チェックと画像で見直しました（`HAND_CFG.barrePole`）。
  - セーハ（人差し指1本で何本もの弦を押さえる形）：人差し指を弦に垂直に立てず、斜めに寝かせて、付け根からG側の端の弦へ滑らかにのばします。付け根が指板に近すぎて骨が余り、第二関節が「く」の字に折れる（最大179°→112°）ことがないよう、付け根と腹の線の入口の距離を骨の長さの6割以上にし（`HAND_CFG.barreReach`）、残りの指（中・薬・小）は人差し指のすぐ脇に指1本ぶんずつ離して置きます（拳のように丸まらない）。
  - 開放弦だけのコード（C6・Am7 など）は、指を宙に浮かせず、弦のすぐ上（2〜4mm）に軽く添えます。待つ指の第二関節は深く曲げすぎない（82°を超えるとコストが増える）ようにしました。
  - 押さえる指から先に形を決め、ほかの指とぶつかる時は指を曲げる面を少しひねって（少し横に開いて／閉じて）よけます。同じフレットで離れた弦を押さえる時は前後に大きめにずらします。使わない指は、力を抜いた形（付け根を少しそらせ、第二関節で軽く曲げる）のまま弦の少し上に浮かせ、押さえている指にかぶさりません。全168コードで、指どうしが重なる所は14か所→0か所になりました（ギター・ハンドガイドと同じしくみ）。
  - 親指は付け根・まん中・先の3つの関節を、人が実際に曲げられる範囲の中だけで動かして形を決めます（`src/thumb.js`）。
  - 手のひらはネックの裏側、ネックを親指と人差し指の股で深くはさみ、親指は付け根〜まん中の節をネックの上の肩（4弦Gの側）にかけて、先を上からのぞかせます。指は1弦（A）側からネックを回り込み、少し斜めに立てて弦を押さえます。前腕は体の側から来て、手首で曲がります。
- **ウクレレ**：コンサートサイズの実寸（Kala KA-C を参考）。弦長381mm、ボディ長281mm、アッパー152mm、ウエスト125mm、ロワー210mm、厚み70mm、サウンドホール直径52mm、18フレット。

## ファイルの構成（さわる人向け）
- `index.html` … 完成品（これだけで動きます）
- `src/` … 元のプログラム（`app.js` 画面・音、`pose.js` 手の形の計算、`handrig.js` 手のモデル、`uke.js` ウクレレのモデル、`view.js` 3D表示、`thumb.js` 親指、`strum.js` 右手のストローク、`data.js` コードと曲のデータ）
- `src/` を直したら `npm install` → `npm run build` で `index.html` を作り直します。

## 動作環境
WebGL が使えるブラウザ（Chrome / Edge / Safari / Firefox の最近のもの）。古いスマホでは動きが重いことがあります。
